Maintain password communication templates

Keep the credential message content controlled in one place. Use the placeholders below so the system can inject the employee full name, selected system name, username, and password automatically.

Available placeholders

{{ '{fullEmployeeName}' }} / {{ '{{fullEmployeeName}}' }}

The employee full name built from first name, middle name, and last name. Both token styles are supported.

{{ '{username}' }} / {{ '{{username}}' }}

The username entered by the administrator for new user creation SMS. Both token styles are supported.

{{ '{systemName}' }} / {{ '{{systemName}}' }}

The system selected at send time, such as Flexcube Core banking, Check Point System, Webmail, or BI Report.

{{ '{password}' }} / {{ '{{password}}' }}

The password entered at the time of dispatch for either reset or new user creation. Both token styles are supported.
